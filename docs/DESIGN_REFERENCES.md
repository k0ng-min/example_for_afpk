## 2. 이미지에서 확인한 요소 → FINOVA 적용
| Wirely에서 관찰 | FINOVA 적용 |
|---|---|
| 흐린 블루그레이 배경 위 큰 반투명 유리 틀(모서리 약 28px) | `body` 배경을 겹친 그라데이션으로 직접 구성(사진 없음) + 화면 전체를 감싸는 유리 틀(`.glass`, 28px) |
| 틀 안 상단 바: 로고 · 아이콘 · 사용자 | 로고 · 한국어 알약 메뉴 · 검색(Ctrl K) · 아이디어 설정 · 고객 프로필 |
| 얇은 제목 "My Portfolio", 작은 경로 표시 | 화면 제목 Outfit/Pretendard Light 30px, 위에 "재무설계 › n단계" 경로 |
| 큰 금액(Light), 소수부 작게 | 순자산 44px ExtraLight, 단위(원·만·%·개월)는 `.unit`으로 작고 흐리게 |
| 상단 오른쪽 통계 줄(라벨 + 숫자, 카드 없음) | 주제 KPI 4개를 카드 없이 나열(`Readout`) |
| 반원 아치 게이지 68% + 점 | **목표 달성 아치**(`GoalArc`): 채움 = 기한 내 달성 가능한 목표 비율, 점 = 목표(채움 기한 내/비움 지연) — Rust 계산 결과 |
| 알약형 계좌 칩 + "+" 원형 버튼 | 고객 선택 알약 + 고객 정보 편집 원형 버튼 |
| 반투명 흰 카드 + 원형 아이콘 버튼 목록 | "분석 요약": 강조 알약 수치, 원형 근거 버튼, 위험 목록 |
| 스틸블루 그라데이션 강조 카드 하나 | "빠른 시나리오 비교"(화면당 강조 카드 하나 원칙) |
| 채도 낮은 단색 계열 | 블루그레이 팔레트, 강한 색은 상태 표시에만 |

## 3. 토큰
| 토큰 | 값 | 용도 |
|---|---|---|
| 배경 | #DFE6EE → #C4D0DD, 블루그레이 블롭 #9EB0C4 | 바탕 |
| `--glass` | rgba(255,255,255,.5) + blur 22px + 흰 1px 테두리 | 패널 |
| `--text` / muted / dim | #1C2431 / #5F6B7C / #8D97A6 | 글자 |
| `--primary` | #3D5C88 (스틸블루) | 주요 동작, 게이지 |
| 강조 카드 | #8AA0BD → #5F7799 그라데이션 | 화면당 1개 |
| 상태 | ok #2F8A6E · warn #A8732A · danger #BF4F4F | 상태 전용 |
| 주제 액센트 | 채도를 낮춘 6색(blue/violet/emerald/amber/rose/cyan) | 주제 정체성 |

- **서체**: Pretendard Variable(한글 UI, SIL OFL 1.1) + **Outfit**(숫자·영문 브랜드, SIL OFL 1.1 — github.com/Outfitio/Outfit-Fonts에서 확인, Google Fonts로 로드).
- **차트 범주색**(밝은 유리 면 #EEF2F7 기준 검증기 전 항목 PASS): `#3060A8 #20907A #B57D22 #7E60C6 #C4547D #2F93C9`. 이전에 저장된 시나리오 색은 프론트엔드에서 자동 변환해 표시.
- **모양**: 버튼·칩·탭은 완전한 알약형, 패널 24px, 입력창 14px, 아이콘 버튼은 테두리 원형.
- **다크 테마 제거**: 요청한 "화이트·소프트 블루" 방향에 맞춰 밝은 테마 하나로 통일.

## 4. 3D·외부 에셋
- 이전 디자인의 three.js 3D 지평선은 **제거**했다(Wirely의 평면 유리 스타일과 맞지 않고 화면을 복잡하게 만듦). `three`, `@react-three/fiber` 의존성도 삭제.
- 입체감은 유리 패널의 블러·하이라이트·부드러운 그림자로만 표현. 외부 이미지·3D 모델·일러스트는 사용하지 않음.
- 아이콘 lucide-react(ISC), 로고 SVG 직접 작성.
