# 최종 아이디어 — 「합격해도 끝나지 않는다」 구현 문서

CPA 수험생의 소득 공백을 대비하는 AI 기반 조건부 재무설계. 1차 기준은 `AFPK_최종_아이디어_기획서_CPA_유예생_재무설계.pdf`(2026.11.11, 18쪽)이다.
가상 고객 김유예는 **합성 데이터**이며, 기획서의 예시 수치는 하드코딩하지 않고 Rust 엔진이 같은 가정으로 독립 재계산한다.

## 1. 화면 구성 (최종 제출 사이트, 2026-11-11 디자인 개편)

모던 블랙 & 화이트(밝은 바탕 + 검은 강조)로 통일했다. 색은 의미 전달용(초록 통과·앰버 부족·보라 AI)과 전략 구분에만 쓴다. 이전 범용 워크스페이스(`/workspace`)는 삭제했고 해당 주소는 홈으로 이동한다.

| 경로 | 화면 | 단계 | 핵심 |
|---|---|---|---|
| `/` | 홈 | 1 | 스크롤 없는 한 화면(데스크톱 1366×768 이상): 핵심 메시지 + 지금 필요한 판단 → 현재 상태 4지표 → 18개월 vs 60개월 요약. 데모 안내 기능은 제거(2026-11-11) |
| `/client` | 고객 정보 | 2 | 기본 상황·18개월 현금흐름·자산·부채·일정과 소득 공백·가정 및 계산 기준. 적용 전 변경 바(바뀐 값과 재계산 결과 미리보기), 학자금 의무상환 계산기 |
| `/canvas` | AI 분석 | 3 | 고객 상황 → 소득 공백 → 필수지출 → 안전자금 → 18개월 판정 → 전략 비교 → 60개월 → AI 제안 → 엔진 검증 → 전환 규칙(React Flow). 카드마다 만든 주체(고객 입력·계산 엔진·AI·검증) 표시 |
| `/copilot` | AI 상담 | 3 | 지급능력 질문 6개에 규칙 기반 답변(엔진 계산), 요청 시에만 생성형 AI 문장 + 숫자 자동 대조. 합격 예측·수험 코칭 질문은 범위 밖 안내 |
| `/simulator` | 시뮬레이션 | 3·4 | 선택 전략 요약 → 18개월 잔액·하한 → 전환 조건 도달 시점 → 60개월 요약 → 상세 근거(접힘). 탭: 합격 후 지연(**첫 급여 지연 0~9개월 범위 팬 차트** 추가), 장기 가치, **무엇이 결과를 바꾸나**(민감도 토네이도·스트레스 테스트 표·18개월 돈의 흐름 폭포·공적 지원/대출 비교 — `finance/cpa_gap/explore.rs`, `POST /api/cpa/explore`) |
| `/verification` | AI 검증 | 4 | 실제 AI 원출력 E1~E8, 주장별 대조표(AI 값·엔진 계산값·허용 오차·판정), AI 1차 검토 의견(판정 아님), 사람의 판정 기록 |
| `/plan` | 실행 계획 | 5·6 | **월별 점검 기록**(실제 월말 잔액 → 계획 대비 차이·점검선 판정·그 잔액에서 재계산, `POST /api/cpa/checkin`, 기록은 브라우저 저장), 신호 1~4 카드, 월별 실행표(지원 감소·신호·발표 후 재계산·수습 미확보 시 취업 전환 검토·부채 조건 재확인), 재점검 체크리스트 |
| `/report` | 보고서 | 6 | 문제 정의 → 고객 상황 → 가정 → AI 분석 → 시나리오 비교 → 독립 검증 → 전환 규칙 → 실행 계획 → 한계. 인쇄·PDF |

검증 상태(공통): 아직 실행하지 않음 · 계산 일치 · 검토 필요 · 근거 부족 · 오류 발견 · 수정 완료. “계산 일치”는 엔진 독립 계산과 허용 오차 안에서 맞을 때만 자동 표시되고, 최종 판정은 사람이 기록할 때 바뀐다.

## 2. 계산 모델 (`backend/src/finance/cpa_gap/`)

```
C(t) = C(t−1) + 실제 현금유입 − 필수생활비 − 수험비 − 실제 채무지급액
τ    = C(t) < Cmin 이 처음 발생한 달
월중 최저 = C(t−1) + 월초 유입(가족 지원·미확인 유입) − 이번 달 지출   (근로·급여는 월말 입금)
V    = p × [ q × V(수습 확보, L) + (1 − q) × V(미지정) ] + (1 − p) × V(불합격)
V(경로) = Σ 순현금흐름ₜ / (1 + r/12)ᵗ ,  t = 1…60
```

- 금액: 정수 원(i64). 현재가치·기대가치만 rust_decimal → 원 단위 반올림(0.5 이상 올림).
- 전략: A 전업 / B 처음부터 병행 / C 수험 중단 후 구직(수험비 0) / D A로 시작해 월말 잔액 ≤ 신호 1이면 `partTimeLead`개월 뒤 근로, ≤ 신호 2이면 구직(임금 입력 시 `jobLead`개월 뒤 급여).
- 수험비는 수험 상태(전업·병행)에서만 발생. 근로·수습·구직 상태에서는 0.
- 결과 상태: 결과 미반영(기준선) / 합격·수습 확보(발표 다음 달 + L에 첫 급여, 수습 기간 후 수습 이후 급여) / 합격·미지정·불합격(발표 후 `jobLead`개월 뒤 취업 임금).
- 지연 내성: 발표 달까지 안전자금 이상일 때, 발표 이후 안전자금을 유지하는 연속 개월 수(기준선 경로, 수습 급여 수준과 무관).
- 시계 1 통과 = 기준선 18개월에 τ 없음 + 월중 지급 불능 없음 + 필요한 입력 완비. 순위·p×q 지도의 승자는 통과 전략만.
- p 하락폭: B는 항상, D는 근로 시작이 시험 월 이전일 때만. C는 p와 무관.

### 임금 기본값(조사 자료 기반, 검증 필요)
| 항목 | 기본값(세후 월) | 근거 |
|---|---|---|
| 수습 기간 | 320만 원 | 대형 회계법인 수습 연봉 6천만~7천만 원, 4천만~5천만 원대 인하 검토 보도(아시아경제 2025.03) → 보수적으로 연 4,500만 원 |
| 수습 이후 | 410만 원 | 같은 보도의 현행 하단 연 6,000만 원 |
| 취업 전환 | 270만 원 | 경총 「대졸 초임 분석」(2025.01) 정규직 평균 연 3,675만 원 |

세후 환산은 4대보험(근로자 부담 약 9.4%)·간이세액 근사이며 고객의 실제 제안 금액이 있으면 그 값으로 바꾼다. 비우면 해당 경로는 `missing`으로 표시하고 계산하지 않는다.
기획서 수치 재현(3장)과 AI 실험 E1~E8 대조는 기획서와 같은 **임금 미입력 가정**(`PDF_BASELINE`)으로 계산한다. 임금 기본값을 넣으면 D는 신호 2(2028.01)에서 취업 전환해 18개월 안에 하한에 닿지 않고, 60개월 비교(p=45%, q=70%)에서는 C가 1위가 된다.

## 4. 기획서와 달라진 점·추가 가정

- 근로 결정 → 첫 소득 준비 기간(`partTimeLead`, 기본 1개월)과 구직 → 첫 급여(`jobLead`, 기본 3개월)를 별도 변수로 두었다(기획서 09 예시와 같은 결과를 내는 값이 기본값).
- 시험 후 수험비 월 5만 원은 수험 상태가 유지되는 동안 계속 발생한다고 보았다(기획서 그래프와 일치).
- 월중 지급 가능 여부(가족 지원 월초, 근로소득 월말)를 추가했다.
- 60개월 모형의 기본 p=45%, q=70%, 하락폭 5%p, r=5%는 기획서의 민감도 격자 값이며 예측이 아니다. 61%(유예생 집단 합격률)는 자동 적용하지 않는다.
- p×q 지도는 10~90%를 5%p 간격으로 계산한다.

## 5. AI 활용·검증 구조

- 실험 정의: `ai/prompts/verification/cpa_experiments.json` (E1~E6 위험·판정 방법·근거 자료 [S1]~[S9]·프롬프트·규칙 힌트).
- `POST /api/cpa/ai/run`: 서버가 Gemini를 호출하고 모델명·실행 시각·프롬프트·원출력을 그대로 반환. 키가 없으면 503(실행하지 않음).
- `POST /api/cpa/ai/screen`: 붙여 넣은 다른 AI의 원출력에서 확인할 문장 후보를 찾는 **규칙 힌트**(판정 아님).
- 상태: 원출력 없음 → “아직 실행하지 않음”, 원출력만 → “검증 필요”, 사람이 사유와 함께 기록해야 “검증 완료 / 일부 검증 / 오류 발견”.
- 엔진 대조: E2 지연 내성, E4 가짜 월 상환액 / E5 미확인 지원금을 넣었을 때 τ 변화, E6 지급능력 검사 유무에 따른 승자 비교.
- 기록은 브라우저 저장소에만 저장되고 JSON으로 내보낸다. 이 저장소에는 **실제 실험 결과가 기록되어 있지 않다**(개발 중 연결 확인용 호출 2회는 저장하지 않음).

## 5-1. 실제 AI 실험 기록 (2026-11-11)

- `ai/evaluations/cpa_experiment_runs.json`: 서버가 Gemini API(gemini-3.5-flash, 혼잡 시 gemini-flash-lite-latest)를 실제 호출한 E1~E8 원출력(편집 없음)과, 원출력에서 옮겨 적은 주장 23개.
- 첫 실행 묶음(04:45 UTC)은 출력 토큰 한도 2048로 응답이 잘려(사고 과정 문장 노출) 폐기했다. 한도 8192·thought 파트 제외·잘림 표시를 적용한 뒤 다시 실행한 결과만 실었다.
- 엔진 대조 결과(기본 가정): 계산 일치 6 · 오류 발견 7 · 검토 필요·근거 부족 10. 예: E2 합격 다음 달 즉시 입사 가정, E5 서울시 청년수당·월세지원을 자격 확인 없이 유입, E6 9개월 부족 자금 310만 원(엔진 995만 원), E8 근거 없는 연 5% 수익률로 5년 뒤 1.47억 원 확정 제시.
- “AI 1차 검토 의견”은 Claude Code가 쓴 참고 의견이며 판정이 아니다. 사람의 판정은 비어 있다(팀이 기록해야 함).

## 5-2. 인터넷 조사로 보완한 사실 (2026-11-11)

- 취업 후 학자금 의무상환: 2025년 귀속 상환기준소득 1,898만 원(총급여 2,851만 원), 초과분 20%(대학원 25%), 원천공제 2026.7.1.~2027.6.30. — 국세청 보도자료(2026.04.20.) [S4]. 엔진 `finance/cpa_gap/icl.rs` 와 `POST /api/cpa/icl` 로 구현(근로소득공제 소득세법 제47조). 2026년 이후 귀속 기준은 미공표 → 최신값 대용 + “검증 필요” 표시.
- 2027년 제62회 시행계획: 2026-11-11 검색 시점 미공고(제61회는 2025.11.24 공고). 2026년 제2차 6월 27~28일 시행·9월 1일 최종 발표 → 2027.06 시험·2027.09 발표로 두고 공고 후 확인.
- 수습 급여·취업 임금: 공식 통계는 없어 보도·경총 조사로 기본값을 넣음(위 표).

## 6. 미완성·추후 작업

- E1~E8 실제 실행은 완료(Gemini). 사람의 최종 판정 기록과 다른 AI 도구(교차 사용) 원출력 기록은 팀 작업으로 남음.
- 2027년 시행계획 공고(예년 11월 말) 후 시험·발표 월 확인, ICL 2026년 귀속 기준 공표 후 갱신.
- 병행 시 p 하락폭은 가정값 — 근거 자료 없음.
- 프론트엔드 단위 테스트(Vitest)는 추가하지 않았다. 계산은 모두 Rust 테스트로 검증하며 프론트엔드는 표시만 한다.
