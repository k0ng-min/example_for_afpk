## 프로젝트 목적
AI 분석과 검증 가능한 Rust 재무 계산을 결합해 표준 재무설계 6단계를 하나의 흐름으로 수행하는 웹앱을 만들고,
최종 아이디어가 정해지면 공통 시스템을 유지한 채 주제에 맞게 재구성(Adaptive Idea Engine)한다.

## 핵심 차별점
1. **AI Reasoning Canvas** — 판단 근거를 노드 그래프로 남기고 실시간 계산값과 연결
2. **Financial Scenario Lab** — 조건 변경 즉시 Rust 엔진 재계산·비교
3. **Verification Lab** — AI 주장마다 독립 재계산, 근거 없는 주장은 자동으로 '검증 완료'가 될 수 없음, 인간 판결 기록
4. **Adaptive Idea Engine** — 아이디어 입력 → 분석 → 구성 생성 → 검증 → 미리보기 → 승인 적용 → 롤백
