# FINANCIAL_ASSUMPTIONS — 계산식·가정·반올림

구현: `backend/src/finance/`. 결과는 **입력 가정에 따른 결정론적 추정치**이며 미래를 보장하지 않는다.

## 단위와 반올림
- 금액: 원 단위 `i64`. 이율·비율: bp 정수(550 = 5.50%). f32/f64는 금액 계산에 사용하지 않는다.
- 이자·수익: `rust_decimal`로 `금액 × bp ÷ 10000 ÷ 12` 계산 후 **0.5원 이상 올림(MidpointAwayFromZero)** (`rounding::apply_rate`).
- 비율: `분자 × 10000 ÷ 분모` 반올림(bp). 비상자금 커버리지: `현금 × 10 ÷ 월 필수지출` 반올림(0.1개월).
- 필요 월저축: 올림 나눗셈.

## 기간
- 월 단위, 0개월 차 = 현재 상태, 1~H개월 시뮬레이션(H = 1~360, 기본 60).
- 이벤트: `startMonth`~`endMonth`(포함, 없으면 끝까지). 일회성 이벤트는 `startMonth`에만 1회.

## 현실 패턴 (`finance::pattern`, 고객의 선택 필드 `pattern`)
실제 가계처럼 달마다 다른 현금흐름을 **결정론적으로**(난수 없이) 만든다. 같은 입력이면 항상 같은 결과다.
- 달력 월 = `(시작 월 − 1 + 시뮬레이션 월 − 1) mod 12 + 1`. 합성 고객은 시작 월 = 11월(계절 변동 0, 연간 항목 없음)로 두어 1개월 차 지표가 평상월 값과 같다.
- 연 인상률: 경과 연수 y = ⌊(월 − 1) ÷ 12⌋, 소득·고정지출·변동지출에 `연 bp`를 y번 복리 적용(매년 원 단위 반올림). 13개월 차부터 반영.
- 변동지출 계절성: 인상 반영 후 변동지출 × (1 + 해당 달력 월 bp ÷ 10000). 테이블은 비우거나 정확히 12개.
- 연간 정기 유입(상여금·환급)·유출(명절·보험·세금): 해당 달력 월의 일회성 유입·유출로 더한다.
- 사업 매출 계절성: 매출 = 기본 매출 × (1 + 시나리오 변화율) × (1 + 해당 달력 월 bp).
- 시나리오 조정(소득·지출 증감)은 인상률 적용 뒤에 더한다(조정액 자체는 인상하지 않음).
- 검증: 시작 월 1~12, 계절성 bp −9000~20000, 인상률 −5000~5000bp, 항목 금액 0 이상, 항목 최대 24개.
- 합성 패턴 값은 모두 가정이며 통계가 아니다(`scripts/setup/gen_sample_data.py`에서 생성).

## 월 계산 순서 (`projections::project`)
1. 소득 = 기본 소득(연 인상 반영) + 소득 조정 + 소득 이벤트 (음수가 되면 0)
2. 생활비 = 고정 + 변동(연 상승·계절성 반영) + 각 조정 + 지출 이벤트, 가족지원 = 재설정값 또는 기본값. 연간 정기 유입·유출은 일회성 순액에 포함
3. 현금 이자 = 현금 × 현금수익률 ÷ 12 (현금이 양수일 때만)
4. 부채(각각): 이자 = 잔액 × 연이율 ÷ 12, 납부 = min(약정 상환 + 추가상환, 잔액 + 이자), 원금 = 납부 − 이자.
   - 추가상환은 **잔액이 남은 가계부채 중 금리가 가장 높은 것** 한 건에 적용(애벌랜치).
   - 납부 < 이자이면 잔액 증가 → `NEGATIVE_AMORTIZATION` 경고.
5. 사업(프로필이 있을 때, `finance::business`): 사업 현금 += 매출×(1+변화율) − 운영비 − 대표자 인출 − 사업부채 납부.
   음수가 되면 `householdBackstop=true`일 때 부족분 전액을 가계에서 이전(전염), `false`면 미지급 부족분으로 부채에 집계.
6. **가계 순현금흐름** = 소득 − 생활비 − 가족지원 − 가계부채 납부 + 일회성 순액 − 사업 이전. **음수를 그대로 표시**한다.
7. 현금 += 순현금흐름 + 현금 이자. 이후 월 투자 이체 = min(설정액, max(현금,0)).
8. 투자자산 += 투자자산 × 기대수익률 ÷ 12 + 이체액.
9. 총자산 = max(현금,0) + 투자 + 기타자산 + max(사업현금,0). 총부채 = 가계·사업부채 + 음수 현금(부족 자금) + 사업 미지급 부족분. 순자산 = 총자산 − 총부채.

## 목표 평가 (`goal_priority`)
- 비상예비자금 = 비상자금 목표 개월 × (1개월 차 생활비 + 가족지원 + 가계부채 납부)
- 가용 유동자산 = 현금 + 투자 − 비상예비자금
- 우선순위(같으면 목표 시점) 순으로 **누적 목표액**을 계산, 가용 유동자산 ≥ 누적 목표액이 되는 첫 달 = 달성 월.
- 기한 내 = 달성 월 ≤ 목표 시점. 부족액 = 목표 시점의 가용 유동자산 − 누적 목표액.
- 필요 월저축 = ⌈(누적 목표액 + 예비자금 − 현재 현금·투자) ÷ 목표 개월⌉ (수익률 미반영 단순 적립).
- 목표 달성 시 자금을 실제로 지출하는 것으로 처리하지 않는다(적립 여부 판단용).

## 지표 레지스트리 (`finance::metrics::METRIC_DEFS`)
monthly_income, essential_expenses, monthly_surplus, savings_rate_bps, debt_service_ratio_bps, family_support_ratio_bps, emergency_fund_months_x10, total_assets, total_liabilities, net_worth, debt_to_asset_bps, total_interest_paid, household_debt_free_month, min_cash, cash_runway_month, negative_cashflow_months, final_net_worth, goal_count, goals_on_track, primary_goal_gap, primary_goal_achieved_month, primary_goal_required_saving, total_household_transfer, business_cash_depleted_month.
1개월 차 기준 지표(소득·순현금흐름·비율)는 시나리오 조정이 반영된 1개월 차 값이다. 3개월 차 이후 이벤트는 기간 지표(최저 현금, 소진 시점 등)로 확인한다.

## 기본 가정
- 투자 기대수익률 기본 연 3%(300bp), 현금 수익률 0% — 사용자가 시나리오에서 변경 가능한 가정값
- 기타 자산(보증금 등) 불변. 물가상승은 고객별 `annualExpenseGrowthBps` 가정으로만 반영, 세금은 연간 정기 유출 항목(예: 종합소득세)으로만 반영, 확률적 변동 미반영
- 분석 규칙 임계값(저축률 10%, 부채상환비율 30%, 비상자금 3개월)은 **내부 점검 기준이며 법정·규제 기준이 아니다**
- 합성 고객의 누락 값(이자율, 지출 분할 등)은 각 고객의 `assumptions`에 명시

## 시나리오 가정
시나리오는 고객 기본값 위에 얹는 조정값(`ScenarioAdjustments`)이며, 복제는 깊은 복사로 원본과 독립이다. 목표 변경 시나리오는 `goals` 배열로 고객 목표를 대체한다.
