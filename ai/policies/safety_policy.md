# AI 안전·검증 정책

1. **계산 권한 분리**: LLM 은 숫자를 생성하지 않는다. 모든 수치는 Rust 엔진 결과만 사용한다.
2. **신뢰할 수 없는 입력**: 아이디어 입력, 생성된 주제 구성, 사용자 질문은 모두 데이터로 취급한다.
   - 서버는 `deny_unknown_fields` 역직렬화 + 허용 목록 enum + `validate_topic` 으로 재검증한다.
   - `<script`, `javascript:`, `{{`, `${` 등 코드/템플릿 패턴이 포함된 텍스트는 거부한다.
3. **코드 실행 금지**: LLM 이 생성한 JavaScript·Rust·셸 명령을 런타임에서 실행하지 않는다.
   새 계산이 필요하면 `requiresDevelopment` 로 표시하고 Claude Code 개발 작업(방식 A)으로 구현한다.
4. **허위 생성 금지**: 확인되지 않은 제도·통계·수익률은 "확인 필요"로 표시한다. 지원하지 않는 질문은 답하지 않는다.
5. **검증 상태 무결성**: '검증 완료'는 독립 계산 비교를 통과한 경우에만, '수정 완료'는 인간 수정값이 재검증을 통과한 경우에만 표시한다.
6. **비밀값**: API 키는 서버 환경변수에만 존재하며 로그·응답에 포함하지 않는다.
